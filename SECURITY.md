# Security Policy

Security updates, bug fixes, and maintenance releases are actively provided for supported release branches:

| Version | Status | Supported |
| :---: | :---: | :---: |
| **1.0.x** | Current Production Release | **Yes** |
| Pre-release / Snapshots | Experimental | Best-effort |

---

## Reporting a Vulnerability

If you identify a security issue, vulnerability, or critical defect affecting **TerraFormaBuilder**, please report it responsibly before any public disclosure:

1. **Email Details**: Send a description of the issue to **`kyroxova@gmail.com`** with the subject line:  
   `[SECURITY] TerraFormaBuilder Vulnerability Report`
2. **Private Advisory**: Alternatively, submit a private advisory through GitHub Security Advisories on the repository.

### Information to Include:
- A clear description of the vulnerability and its potential impact.
- Affected Minecraft releases, mod loaders (Fabric, Forge, NeoForge), and TFB version.
- Step-by-step reproduction instructions or proof-of-concept design plan.
- Relevant log files, stack traces, or configuration settings.

The maintenance team at **x64Dynamics** will review and respond to reports promptly, investigate the issue, and coordinate an official patch release.
