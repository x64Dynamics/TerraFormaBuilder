# 🏛️ TerraFormaBuilder (TFB)

**The Next-Generation Procedural Architecture & Construction Studio for Minecraft.**

**Developed by x64Dynamics | Lead Developer: KyroXova**

---

### Overview

**TerraFormaBuilder** is an intelligent architectural design and automated construction studio that allows players, builders, and server administrators to design, customize, preview, and generate complex architectural structures, civil infrastructure, and furnished buildings directly in Minecraft worlds without manually placing millions of individual blocks.

> **"The player is the architect. TFB is the construction engine."**

Unlike traditional schematic tools, TerraFormaBuilder uses an **advanced procedural geometry engine**. Foundations dynamically adapt to changing terrain elevations, facades generate contextual windows, pediments, and arches, roofs automatically calculate appropriate pitches and overhangs, and road networks follow smooth Bezier and Catmull-Rom splines with realistic intersections and roundabouts.

---

### Key Features

* **Procedural Architectural Brushes**:
  - Rectangular, polygonal, circular, elliptical, L-shaped, T-shaped, and irregular buildings.
  - Multi-storey wings, attached towers, colonnades, and courtyards.
  - Contextual facades, arches, pediments, pillars, and balustrades.
  - Parametric roofs: Gabled, hipped, mansard, gambrel, flat parapet, domed, and pagoda.
  - Functional interior floorplans and procedural room furnishing.

* **Civil Infrastructure & Spline Roads**:
  - Smooth Bezier & Catmull-Rom road splines with interactive tangent control.
  - Configurable widths, sidewalks, road markings, curbs, and street lighting.
  - Automatic generation of intersections, T-junctions, and roundabouts.
  - Elevation transitions: Embankment bridges, retaining walls, and bored tunnels.

* **Dedicated In-Game Architect Mode & Builder Hotbar**:
  - Dedicated 9-slot **Builder Hotbar** replacing survival hotbar display in Architect Mode.
  - Instant category cycling (`Shift + Mouse Wheel`) across Architecture, Infrastructure, Editing, and Decoration.
  - Number keys `1`–`9` direct selection with active tool pill indicators.
  - 3D WASD free-flight movement with velocity physics and flight speed tuning (`[` / `]`).
  - Persistent studio HUD banner showing tool status, coordinates, dimensions, and estimated block count.

* **Non-Destructive Building Studio**:
  - Real-time in-world 3D wireframe and voxel preview (`P`).
  - Multi-level Undo (`Ctrl + Z`) and Redo (`Ctrl + Y` / `Ctrl + Shift + Z`).
  - Instant construction plan execution (`G`) directly placing blocks into the level.
  - Cohesive material taxonomy with smart structural palette assignments.

### Controls & Keybindings

| Key | Action | Description |
| :--- | :--- | :--- |
| **`B`** | **Open Architect Workspace** | Opens the main design workspace interface. |
| **`P`** | **Toggle Live Preview** | Toggles real-time 3D bounding boxes and preview voxels. |
| **`G`** | **Execute Build** | Validates and places the active construction plan. |
| **`Ctrl + Z`** | **Undo** | Undo the latest design action in the workspace. |
| **`Ctrl + Y`** | **Redo** | Redo the latest undone design operation. |
| **`1` – `9`** | **Select Slot** | Selects the corresponding tool slot on the builder hotbar. |
| **`Mouse Wheel`** | **Cycle Tools** | Cycles forward/backward through tools in the active category. |
| **`Shift + Scroll`** | **Cycle Page** | Flips between tool categories on the builder hotbar. |
| **`[` / `]`** | **Adjust Flight Speed** | Adjusts 3D free-flight speed by 0.2x. |
| **`Esc`** | **Close Workspace** | Closes interface while preserving the active design plan. |
