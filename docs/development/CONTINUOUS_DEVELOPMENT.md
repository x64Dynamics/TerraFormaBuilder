# TerraFormaBuilder — Continuous Development & Agent Handoff Protocol

## Operating Instructions for Autonomous Agents

This document defines the persistent handoff state, execution checkpoints, and continuation instructions for any agent session (Antigravity, Codex, or Claude Code) resuming development on TerraFormaBuilder.

---

## 1. Operating Rules & Core Directives

1. **Non-Stop Execution Invariant**:
   - Never stop work merely because a single target compiles or a milestone is reached.
   - Even when external account rotation prompts appear (*"accounts rotated start working where you left off"*), keep the goal active and resume immediate concrete implementation.
2. **Multi-Version Parity Requirement**:
   - Single-version shortcuts are prohibited.
   - Features implemented on one loader/version (e.g. 1.21.1 NeoForge) must be ported and maintained in lockstep across all other supported versions (e.g. 1.20.1 Fabric, Forge targets, 26.x).
   - Core algorithms, data structures, and math must live in `common/`.
3. **No AI Attribution**:
   - Never include AI or agent attribution trailers (`Co-Authored-By`, `Generated by`).
   - Author commits using `@gitAuthor` from `userDefinitions.md`.
4. **Safety & Destructive Command Gating**:
   - Run `check-safety` via `tools/kyro/runner.py` before any bulk or cleanup filesystem commands.
