## Installation & Deployment

### Client Installation (Singleplayer / Multiplayer)
1. Install your preferred mod loader (**Fabric**, **Forge**, or **NeoForge**) for your target Minecraft version.
2. If using **Fabric**, ensure **Fabric API** is present in your `mods/` directory.
3. Download the matching `terraformabuilder-<mc>-<loader>-1.0.0.jar` from the table above.
4. Place the `.jar` file into your `.minecraft/mods/` directory.
5. Launch Minecraft and press **`B`** in any world to enter the Architect Workspace!

### Server Installation
- TerraFormaBuilder can run on dedicated servers as well as internal servers (Singleplayer / LAN).
- Place the matching server JAR into your server's `mods/` directory.
